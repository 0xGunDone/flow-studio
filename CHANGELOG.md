# Changelog

## 1.0.0 — Alpha

Первый публичный desktop-релиз Flow Studio для macOS с Apple Silicon и Intel.

### Возможности

- Electron-интерфейс для генерации изображений и видео через Google Flow.
- Изображения-референсы, начальный и конечный кадры, продолжение видео в поддерживаемых моделях.
- Несколько Google-аккаунтов, отдельные профили Chrome, проверка сессии и повторный вход после ошибки авторизации.
- Асинхронные задачи, предпросмотр, сохранение файлов, открытие Finder и история последних 100 задач.
- MCP-сервер с 13 инструментами, CLI для локального моста и инструкция для агента.
- Исходники Flow2API в составе приложения, сборка локального Docker-образа при первом запуске и локальные учетные данные без общей предустановленной пары логин/пароль.
- Документация по установке, MCP, сборке и диагностике.

### Известные ограничения

- Сборки не подписаны Apple Developer ID и не нотарифицированы.
- Нужны Chrome и Docker Desktop либо Colima с Docker CLI и Docker Compose.
- Выполняется одна генерация за раз. Доступ к моделям и расход кредитов определяются Google-аккаунтом и сервисом.
- Отмена ожидания или выход из приложения не гарантируют отмену задачи у Google.
- Desktop-поддержка Windows и Linux не заявлена.
