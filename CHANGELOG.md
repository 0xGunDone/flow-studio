# Changelog

## Unreleased

- Подготовка загрузки теперь сохраняет отдельные безопасные коды: время ожидания браузера, отсутствующий runtime, ошибка выполнения, отсутствие подтверждения. Технические детали не включают исходные исключения с возможными секретами. Диагностика не меняет проверку Google и не подтверждает восстановление автоматической загрузки.

- Сбой получения подтверждения reCAPTCHA перед загрузкой изображения показывается как локальная ошибка до отправки референса. Сохраняются технические детали; кнопка открывает обычный Flow для ручной проверки без повторной генерации.
- Такой локальный сбой не увеличивает счётчик ошибок аккаунта и не отключает исправное подключение.

## 1.2.1 — Alpha

- В карточках аккаунтов появились тумблер участия в генерации и удаление подключения с подтверждением адреса. История, результаты, Google-аккаунт и данные Chrome сохраняются.
- Ручное отключение сохраняется после обновления сессии, повторного входа, автоматического восстановления и обработки 429, включая параллельное обновление credentials.
- Кнопка «Проверить все включённые» последовательно проверяет активные аккаунты, показывает прогресс и ошибки по каждому, продолжает после отказа одного аккаунта. Выключенные аккаунты пропускаются; генерация не запускается.
- Удаление дожидается фоновой синхронизации и отвязывает профиль. Повторная синхронизация не воссоздаёт удалённое подключение; завершение приложения дожидается сохранения удаления.

## 1.2.0 — Alpha

- Повторный запуск использует готовый образ движка своей версии; сборка нужна только при отсутствии образа.

- Добавлена Omni 1.2 Flash по проверенному каталогу Google Flow: текст, ингредиенты и кадры на 3–15 секунд, 16:9 и 9:16, 720p и 360p. Frames на 3–10 секунд принимают начальный и необязательный конечный кадр, на 11–15 секунд — только начальный; длительности 11–15 секунд требуют Pro или Ultra. Omni 1.2 Edit принимает одно видео до 15 секунд и 100 МиБ плюс до пяти изображений; у Omni 1.1 Edit остается лимит 10 секунд.
- Для нового видео без выбранной модели предпочтительна совместимая Omni 1.2 Flash из текущего каталога; предпочтение доступно агентам через `preferred`. Явный и сохраненный выбор, история, подготовленные запросы и их идентичный повтор сохраняют исходную модель. Автоматической замены на Omni 1.1 нет.
- В MCP добавлен 14-й инструмент `flow_studio_prepare_generation`: точная модель или отдельные настройки проверяются вместе с локальными исходниками без загрузки, создания задачи и расхода кредитов. Каталог поддерживает фильтры режима, семейства, длительности, формата и разрешения; `generate` принимает точный ID или `settings` без автоматической замены недоступного сочетания. Обновлены навык агента, примеры CLI и встроенная справка.
- Выбор генерации разделён на режим, модель, длительность и формат. Для Frames добавлены отдельные слоты начального и конечного кадров с выбором файлов и перетаскиванием; ингредиенты и кадры сохраняются раздельно при смене режима. Доступны только сочетания из каталога движка.
- Фото и видео можно перетаскивать из Finder в область вложений. Поддерживаются несколько файлов, подсветка области и защита от дубликатов; выбор кнопкой и перетаскивание используют одинаковые ограничения форматов, размеров и выбранной модели.
- Исправлено обновление аккаунтов во время запуска: запросы дожидаются готовности движка, кнопка недоступна до подключения. Параллельные обращения используют один запуск, а ошибки чтения локальных настроек отображаются без команд Docker и SQL.
- Локальный движок запускается вместе с Flow Studio и останавливается при закрытии окна или выходе через `⌘Q`. Убран скрытый режим после закрытия; отключён автоматический перезапуск контейнера. Во время генерации можно вернуться к окну или закрыть приложение с остановкой локального ожидания.
- Завершение дожидается сохранения истории и остановки своего сервиса. Исправлена потеря истории при выходе во время начального чтения файла.
- Явные отказы Google `PUBLIC_ERROR_*` больше не повторяются автоматически как технический сбой. Для `PUBLIC_ERROR_MINOR` добавлено осторожное русское объяснение с сохранением кода, без смешивания с `PUBLIC_ERROR_USER_MINOR` или ошибкой входа.
- Отказы проверки содержимого не увеличивают счетчик ошибок учетных данных и не отключают исправный аккаунт. После такого отказа приложение не предлагает безусловно повторить тот же запрос.

## 1.1.0 — Alpha

- Обновлены ключи моделей Veo по текущему каталогу Google Flow, проверенному 27 октября 2026 года. Варианты на 4 и 6 секунд отмечены как требующие Google AI Ultra; добавлены варианты «По кадрам» на 8 секунд для Lite, Fast и Quality.
- Обычный Omni принимает до 7 изображений. Добавлены отдельные модели Omni Edit: одно исходное видео и до 5 изображений. MP4, MOV и M4V проверяются по ограничениям 10 секунд и 100 МБ и загружаются как видео, без извлечения кадров.
- В редакторе доступны выбор нескольких исходных файлов, предпросмотр видео, названия и типы файлов, счетчики, смена порядка стрелками и удаление. Смена модели сохраняет выбор и показывает несовместимые исходники перед отправкой.
- MCP принимает `videoPaths` для Omni Edit вместе с необязательными `referencePaths`; лимиты и режим редактирования видны в каталоге.
- `ffprobe` входит в образ локального движка. Установка FFmpeg на Mac не требуется.
- Обновлены встроенная справка и руководства по исходным файлам, тарифам Veo и MCP. Наличие модели в каталоге по-прежнему не подтверждает доступ аккаунта или успешную генерацию у Google.

## 1.0.1 — Alpha

- Удалена унаследованная константа Google API key и обращение к отключённому устаревшему API. Рабочие запросы Flow используют текущий транспорт и сессии аккаунтов.
- Проверка исходников и состава сборки теперь отклоняет литералы Google API key, GitHub token и приватных ключей. Значения не выводятся в журнал.
- Новые архивы приложения не содержат унаследованной константы. История и исходный выпуск 1.0.0 сохраняются без переписывания.

## 1.0.0 — Alpha

Первый публичный desktop-релиз Flow Studio для macOS с Apple Silicon и Intel.

### Возможности

- Electron-интерфейс для генерации изображений и видео через Google Flow.
- Изображения-референсы, начальный и конечный кадры, продолжение видео в поддерживаемых моделях.
- Несколько Google-аккаунтов, отдельные профили Chrome, проверка сессии и повторный вход после ошибки авторизации.
- Асинхронные задачи, предпросмотр, сохранение файлов, открытие Finder и история последних 100 задач.
- MCP-сервер с 13 инструментами, CLI для локального моста и инструкция для агента.
- Исходники Flow2API в составе приложения, сборка локального Docker-образа при первом запуске и локальные учетные данные без общей предустановленной пары логин/пароль.
- Документация по установке, MCP, сборке и диагностике.

### Известные ограничения

- Сборки не подписаны Apple Developer ID и не нотарифицированы.
- Нужны Chrome и Docker Desktop либо Colima с Docker CLI и Docker Compose.
- Выполняется одна генерация за раз. Доступ к моделям и расход кредитов определяются Google-аккаунтом и сервисом.
- Отмена ожидания или выход из приложения не гарантируют отмену задачи у Google.
- Desktop-поддержка Windows и Linux не заявлена.
