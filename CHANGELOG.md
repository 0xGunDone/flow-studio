# Changelog

## 1.3.0 — Alpha / Pre-release (готовится)

- Поддерживаемые Nano Banana, Omni 1.2 Flash и стандартные Veo 3.1 автоматически используют отдельный фоновый браузер Flow Studio через обычную генерацию. Точная модель, полный запрос, порядок исходников, роли кадров и выбранный аккаунт сохраняются. Ошибка не вызывает повторную платную отправку, смену модели, аккаунта или движка.
- Omni 1.2 поддерживает текст, до семи ингредиентов и отдельные начальный/конечный кадры. Реализован Edit с одним исходным видео и проверкой формата, длительности и точной геометрии выбранного режима; две задачи Agent Edit без дополнительных изображений в 720p, 9:16, около 10 секунд с отдельным восстановлением, скачиванием и сохранением проверены. Скачанный Edit проверяется по точным размерам и длительности исходника с допуском 0,15 секунды; файл свыше 100 МиБ или недоступная проверка дают `OUTPUT_METADATA_UNAVAILABLE`, несовпадение — `MODEL_SETTINGS_NOT_VERIFIED`, без успешного завершения и автоматического повтора.
- Проверка результата связывает полный точный запрос, упорядоченные референсы и постер с одной выбранной записью History. Перед скачиванием эта связь проверяется снова; варианты загрузки открываются только через собственную кнопку записи и ее меню `aria-controls`. Отсутствующая, неоднозначная или изменившаяся связь отклоняется.
- Приватная запись отправки сохраняется до единственного нажатия Generate. Неизвестный исход можно проверить и скачать в ту же запись истории без повторной загрузки исходников и новой генерации. Сохранение через нативный диалог «Сохранить как…» и открытие папки Finder проверены в установленном приложении.
- Участие аккаунта в генерации отделено от состояния его сессии. После относящихся к аккаунту ошибок сохраняется локальный КД на 30 минут. Явный ручной сброс снимает только локальный таймер, сохраняет последнюю ошибку и ручное отключение; ограничения Google и генерацию он не меняет. Проверка включенных аккаунтов работает последовательно и возвращает причину отказа каждого.
- MCP API 3 предоставляет 24 инструмента: локальная подготовка, явный выбор аккаунта, необязательная проверка загрузки без генерации, восстановление прежней задачи, участие аккаунтов, проверка подключений и ручной сброс КД. Поддержан адаптер вне облачной папки; для новой схемы переподключите MCP-клиент. Обновлены навык агента, CLI, руководства и встроенная справка.
- Завершение блокирует новые действия, дожидается собственных операций браузера, моста, истории и backend, обрабатывает SIGTERM/SIGINT и допускает повтор после ошибки остановки без синхронного модального окна. Закрытие останавливает локальное ожидание; Google может завершить уже принятый запрос.
- Сохранены обновленные cookies в пределах задачи без перезаписи более нового входа; проверка email запрещает незаметную смену аккаунта. Ошибки загрузки и отказы содержимого не штрафуют исправный аккаунт. `PUBLIC_ERROR_UNUSUAL_ACTIVITY` сохраняется как отказ конкретной отправки, без утверждения о блокировке всего аккаунта и без автоматического повтора.
- В настройках доступно защищенное сохранение нового API-ключа 2Captcha; существующий ключ не возвращается в интерфейс. Прежние инструменты обычного Chrome остаются отдельным диагностическим маршрутом.
- CI включает backend-набор `test_video_inputs.py`; workflow предварительного релиза повторно использует CI. Итоги CI и сборок фиксируются только для финального исходного коммита.

### Проверено в установленном приложении

- Обычные задачи Omni 1.2 Flash: текст без референсов, один и два разных ингредиента, отдельные начальный и конечный кадры. Подтверждены отправка, прогресс, история, скачивание и сохранение соответствующих MP4.
- Veo 3.1 Lite Ingredients/R2V: 8 секунд, один референс, портрет, 720p; скачан и сохранен MP4 H.264/AAC 720×1280, 24 кадра/с, 7,93 секунды.
- Изображение с двумя разными референсами скачано и сохранено как JPG 768×1376; изображение без референсов восстановлено в 1024×1024. Это не подтверждает все семейства и форматы Nano Banana.
- Существующие изображение с двумя референсами и видео Veo 720p скачаны через выбранную запись History и принадлежащее ей меню. Исходная задача восстановлена по записи отправки с проверкой полного запроса, порядка референсов и постера без новой генерации.
- Существующее портретное изображение Nano Banana 2.1 скачано через собственный пункт 2K Upscaled без новой генерации: 1536×2752 против стандартного 768×1376. Другие семейства, форматы и 4K не заявлены проверенными.
- Нативные «Сохранить как…» и открытие папки, ручной сброс локального КД и последовательная проверка аккаунтов с отдельными ошибками подтверждены.

### Перед публикацией

Omni 1.2 Edit использует Flow Agent в том же принадлежащем приложению браузере: точные аккаунт, модель, запрос, исходное видео и порядок изображений сохраняются. Agent готовит одно предложение на одно видео. Перед единственным Approve приложение проверяет предложение, сохраняет приватную запись отправки и проходит тот же барьер разрешенного расхода; повторного подтверждения, переключения аккаунта или платного fallback нет.

Стоимость собственного предложения Agent должна точно совпасть с расчетом для выбранного режима и целого числа секунд, округленного вверх; для Omni 1.2 секунды сверх десяти учитываются вдвойне. Предварительная проверка прямого редактора использует округление его меню, а расчет Agent — ceil длительности, поэтому для наблюденного исходника 10,026667 секунды Agent показал 36 кредитов вместо 30 в прямом редакторе. Это не удвоенный бюджет и не разрешение менять модель. Совпадение стоимости не доказывает разрешение результата: перед успехом сохраняются проверки точных размеров и длительности.

В установленном приложении проверен непрерывный проход Omni 1.2 Edit через Flow Agent с исходным видео и двумя разными изображениями в точном порядке: полный исходный запрос, одно предложение, одно Approve за 36 кредитов, ожидание, проверка History, скачивание и сохранение без ручного восстановления. Задача завершилась за 279 секунд; MP4 — 720×1280, 9:16, H.264/AAC, 10,026667 секунды. Отдельно проверены задачи без дополнительных изображений и с двумя изображениями, восстановленные по записям отправки без новой генерации. Эти проверки относятся к указанному портретному сценарию 720p; остальные форматы, длительности и успешный 360p Edit не заявлены проверенными.

Для Edit с изображениями приложение сначала отправляет в новой пустой сессии Agent отдельную управляющую инструкцию без вложений: использовать все изображения как ингредиенты в сохраненном порядке, сохранить следующий творческий запрос дословно, создать одно видео и не начинать генерацию или запрашивать Approve до следующего сообщения. Затем исходное видео, изображения и неизмененный запрос отправляются отдельным сообщением. Управляющий контекст видим в Agent, не добавляется к творческому запросу и не меняет его в History. Нужны ровно одна завершенная управляющая пара сообщений и следующая собственная пара запроса/предложения; дополнительные сообщения, преждевременное разрешение или дрейф исходников отклоняются. Единственный платный барьер остается Approve после приватной записи отправки.

Для восстановления Agent запись хранит типизированный IMAGE preview исходного видео и связывает его ресурс с исходной сценой, полным запросом и упорядоченными изображениями выбранной записи History. IMAGE preview не является Google video ID; приложение не выдумывает /video/ идентификатор. Восстановление читает существующий результат, не прикрепляет исходники, не создает новое предложение и не нажимает Approve.

360p продолжает останавливаться до Agent, если прямое меню не подтверждает выбранный режим: живая проверка 9 против ожидаемых трех кредитов для исходника 3 секунды завершилась `MODEL_SETTINGS_NOT_VERIFIED`, без Generate. Финальные тесты и архивы должны относиться к окончательному исходному коммиту; прежние архивы не подтверждают новый код Agent.

## 1.2.1 — Alpha

- В карточках аккаунтов появились тумблер участия в генерации и удаление подключения с подтверждением адреса. История, результаты, Google-аккаунт и данные Chrome сохраняются.
- Ручное отключение сохраняется после обновления сессии, повторного входа, автоматического восстановления и обработки 429, включая параллельное обновление credentials.
- Кнопка «Проверить все включённые» последовательно проверяет активные аккаунты, показывает прогресс и ошибки по каждому, продолжает после отказа одного аккаунта. Выключенные аккаунты пропускаются; генерация не запускается.
- Удаление дожидается фоновой синхронизации и отвязывает профиль. Повторная синхронизация не воссоздаёт удалённое подключение; завершение приложения дожидается сохранения удаления.

## 1.2.0 — Alpha

- Повторный запуск использует готовый образ движка своей версии; сборка нужна только при отсутствии образа.

- Добавлена Omni 1.2 Flash по проверенному каталогу Google Flow: текст, ингредиенты и кадры на 3–15 секунд, 16:9 и 9:16, 720p и 360p. Frames на 3–10 секунд принимают начальный и необязательный конечный кадр, на 11–15 секунд — только начальный; длительности 11–15 секунд требуют Pro или Ultra. Omni 1.2 Edit принимает одно видео до 15 секунд и 100 МиБ плюс до пяти изображений; у Omni 1.1 Edit остается лимит 10 секунд.
- Для нового видео без выбранной модели предпочтительна совместимая Omni 1.2 Flash из текущего каталога; предпочтение доступно агентам через `preferred`. Явный и сохраненный выбор, история, подготовленные запросы и их идентичный повтор сохраняют исходную модель. Автоматической замены на Omni 1.1 нет.
- В MCP добавлен 14-й инструмент `flow_studio_prepare_generation`: точная модель или отдельные настройки проверяются вместе с локальными исходниками без загрузки, создания задачи и расхода кредитов. Каталог поддерживает фильтры режима, семейства, длительности, формата и разрешения; `generate` принимает точный ID или `settings` без автоматической замены недоступного сочетания. Обновлены навык агента, примеры CLI и встроенная справка.
- Выбор генерации разделён на режим, модель, длительность и формат. Для Frames добавлены отдельные слоты начального и конечного кадров с выбором файлов и перетаскиванием; ингредиенты и кадры сохраняются раздельно при смене режима. Доступны только сочетания из каталога движка.
- Фото и видео можно перетаскивать из Finder в область вложений. Поддерживаются несколько файлов, подсветка области и защита от дубликатов; выбор кнопкой и перетаскивание используют одинаковые ограничения форматов, размеров и выбранной модели.
- Исправлено обновление аккаунтов во время запуска: запросы дожидаются готовности движка, кнопка недоступна до подключения. Параллельные обращения используют один запуск, а ошибки чтения локальных настроек отображаются без команд Docker и SQL.
- Локальный движок запускается вместе с Flow Studio и останавливается при закрытии окна или выходе через `⌘Q`. Убран скрытый режим после закрытия; отключён автоматический перезапуск контейнера. Во время генерации можно вернуться к окну или закрыть приложение с остановкой локального ожидания.
- Завершение дожидается сохранения истории и остановки своего сервиса. Исправлена потеря истории при выходе во время начального чтения файла.
- Явные отказы Google `PUBLIC_ERROR_*` больше не повторяются автоматически как технический сбой. Для `PUBLIC_ERROR_MINOR` добавлено осторожное русское объяснение с сохранением кода, без смешивания с `PUBLIC_ERROR_USER_MINOR` или ошибкой входа.
- Отказы проверки содержимого не увеличивают счетчик ошибок учетных данных и не отключают исправный аккаунт. После такого отказа приложение не предлагает безусловно повторить тот же запрос.

- Обновлены ключи моделей Veo по текущему каталогу Google Flow, проверенному 27 октября 2026 года. Варианты на 4 и 6 секунд отмечены как требующие Google AI Ultra; добавлены варианты «По кадрам» на 8 секунд для Lite, Fast и Quality.

- MCP принимает `videoPaths` для Omni Edit вместе с необязательными `referencePaths`; лимиты и режим редактирования видны в каталоге.
- `ffprobe` входит в образ локального движка. Установка FFmpeg на Mac не требуется.
- Обновлены встроенная справка и руководства по исходным файлам, тарифам Veo и MCP. Наличие модели в каталоге по-прежнему не подтверждает доступ аккаунта или успешную генерацию у Google.

## 1.0.0 — Alpha

Первый публичный desktop-релиз Flow Studio для macOS с Apple Silicon и Intel.

### Возможности

- Electron-интерфейс для генерации изображений и видео через Google Flow.
- Изображения-референсы, начальный и конечный кадры, продолжение видео в поддерживаемых моделях.
- Несколько Google-аккаунтов, отдельные профили Chrome, проверка сессии и повторный вход после ошибки авторизации.
- Асинхронные задачи, предпросмотр, сохранение файлов, открытие Finder и история последних 100 задач.
- MCP-сервер с 13 инструментами, CLI для локального моста и инструкция для агента.
- Исходники Flow2API в составе приложения, сборка локального Docker-образа при первом запуске и локальные учетные данные без общей предустановленной пары логин/пароль.
- Документация по установке, MCP, сборке и диагностике.

### Известные ограничения

- Сборки не подписаны Apple Developer ID и не нотарифицированы.
- Нужны Chrome и Docker Desktop либо Colima с Docker CLI и Docker Compose.
- Выполняется одна генерация за раз. Доступ к моделям и расход кредитов определяются Google-аккаунтом и сервисом.
- Отмена ожидания или выход из приложения не гарантируют отмену задачи у Google.
- Desktop-поддержка Windows и Linux не заявлена.
