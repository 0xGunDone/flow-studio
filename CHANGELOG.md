# Changelog

## 1.1.0 — Alpha

- Обновлены ключи моделей Veo по текущему каталогу Google Flow, проверенному 27 октября 2026 года. Варианты на 4 и 6 секунд отмечены как требующие Google AI Ultra; добавлены варианты «По кадрам» на 8 секунд для Lite, Fast и Quality.
- Обычный Omni принимает до 7 изображений. Добавлены отдельные модели Omni Edit: одно исходное видео и до 5 изображений. MP4, MOV и M4V проверяются по ограничениям 10 секунд и 100 МБ и загружаются как видео, без извлечения кадров.
- В редакторе доступны выбор нескольких исходных файлов, предпросмотр видео, названия и типы файлов, счетчики, смена порядка стрелками и удаление. Смена модели сохраняет выбор и показывает несовместимые исходники перед отправкой.
- MCP принимает `videoPaths` для Omni Edit вместе с необязательными `referencePaths`; лимиты и режим редактирования видны в каталоге.
- `ffprobe` входит в образ локального движка. Установка FFmpeg на Mac не требуется.
- Обновлены встроенная справка и руководства по исходным файлам, тарифам Veo и MCP. Наличие модели в каталоге по-прежнему не подтверждает доступ аккаунта или успешную генерацию у Google.

## 1.0.1 — Alpha

- Удалена унаследованная константа Google API key и обращение к отключённому устаревшему API. Рабочие запросы Flow используют текущий транспорт и сессии аккаунтов.
- Проверка исходников и состава сборки теперь отклоняет литералы Google API key, GitHub token и приватных ключей. Значения не выводятся в журнал.
- Новые архивы приложения не содержат унаследованной константы. История и исходный выпуск 1.0.0 сохраняются без переписывания.

## 1.0.0 — Alpha

Первый публичный desktop-релиз Flow Studio для macOS с Apple Silicon и Intel.

### Возможности

- Electron-интерфейс для генерации изображений и видео через Google Flow.
- Изображения-референсы, начальный и конечный кадры, продолжение видео в поддерживаемых моделях.
- Несколько Google-аккаунтов, отдельные профили Chrome, проверка сессии и повторный вход после ошибки авторизации.
- Асинхронные задачи, предпросмотр, сохранение файлов, открытие Finder и история последних 100 задач.
- MCP-сервер с 13 инструментами, CLI для локального моста и инструкция для агента.
- Исходники Flow2API в составе приложения, сборка локального Docker-образа при первом запуске и локальные учетные данные без общей предустановленной пары логин/пароль.
- Документация по установке, MCP, сборке и диагностике.

### Известные ограничения

- Сборки не подписаны Apple Developer ID и не нотарифицированы.
- Нужны Chrome и Docker Desktop либо Colima с Docker CLI и Docker Compose.
- Выполняется одна генерация за раз. Доступ к моделям и расход кредитов определяются Google-аккаунтом и сервисом.
- Отмена ожидания или выход из приложения не гарантируют отмену задачи у Google.
- Desktop-поддержка Windows и Linux не заявлена.
