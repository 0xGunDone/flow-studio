# Безопасность

Flow Studio хранит данные сессий Google, локальные учетные данные движка, запросы и результаты на вашем Mac. Интерфейс локальный, но генерация обращается к Google. Alpha-релиз не является заявлением о проведенном независимом аудите безопасности.

## Как сообщить об уязвимости

Не публикуйте cookies, токены, API-ключи, базу данных, профили Chrome или секрет `agent-bridge.json` в issue, pull request или чат.

Если на странице [Security](https://github.com/0xGunDone/flow-studio/security) доступно **Report a vulnerability**, используйте приватный отчет GitHub. Если приватная отправка недоступна, создайте issue с просьбой предоставить приватный канал, без деталей эксплуатации и чувствительных данных.

В приватном отчете укажите версию, платформу, затронутый компонент, шаги воспроизведения и возможное воздействие. Используйте тестовые данные. Сроки исправления и ответов не гарантируются; проект поддерживается в рамках доступных ресурсов.

## Границы доступа

- Backend по умолчанию слушает `127.0.0.1:38000`. Не открывайте его в интернет и не перенаправляйте порт без отдельного анализа и настройки доступа.
- MCP использует локальный мост на `127.0.0.1` и секрет, созданный приложением. Не передавайте файл моста другим пользователям и не ослабляйте его права доступа.
- MCP-клиент с доступом к мосту может создавать генерации, читать историю, использовать локальные исходники и сохранять результаты с правами текущего пользователя. Подключайте только доверенные клиенты.
- Данные приложения находятся в `~/Library/Application Support/Flow Studio`. Права доступа к папке не заменяют защиту самого Mac и его резервных копий.
- Пароли и коды подтверждения вводятся в интерфейсе Google. Агенту не нужны cookies, пароли и токены для обычной работы через MCP.

## Релизные сборки

Текущие сборки не подписаны Apple Developer ID и не нотарифицированы. Загружайте их из [официальных релизов этого репозитория](https://github.com/0xGunDone/flow-studio/releases) и проверяйте опубликованные контрольные суммы. Не отключайте системную защиту macOS целиком ради запуска приложения.

Не включайте реальные аккаунты, сессии, локальные базы данных, журналы с личными данными или рабочие конфигурации в исходники и релизные архивы. Учетные данные должны создаваться локально при первом запуске.

## Уведомление secret scanning №1 — 16 октября 2026

GitHub обнаружил Google API key в унаследованной константе `FLOW_PUBLIC_API_KEY` версии 1.0.0. Значение совпало с исходным [upstream-коммитом](https://github.com/TheSmallHanCat/flow2api/blob/f6f201c298ee6ee4b28a7d36adf3a8d49cfb2844/src/services/flow_client.py#L33) и с кодом, который Google публично отдавал без авторизации в [JavaScript Google Labs](https://labs.google/fx/_next/static/chunks/pages/_app-897363ab50ff668a.js) на дату проверки. Это не учетные данные пользователя Flow Studio. Проверка происхождения не включала запросов к API с этим ключом.

Константа использовалась только в отключённом устаревшем пути. В 1.0.1 удалены и константа, и запрос, использовавший её. Добавлена проверка, запрещающая литералы ключей в исходниках и содержимом новых сборок. Значение не скрывается кодированием или разбиением строки.

История Git и архивы 1.0.0 по-прежнему содержат исходный upstream-код. Они не переписывались. Это уведомление не свидетельствует об утечке пользовательских Google-сессий, паролей или локальных ключей Flow Studio; сами по себе публичность и формат ключа не доказывают его пригодность или ограничения. GitHub указывал валидность `Unknown`.
