# Диагностика

[← README](../README.md)

## Движок не запускается

1. Прочитайте сообщение запуска в приложении.
2. Убедитесь, что запущен Docker Desktop или Colima, затем проверьте `docker info` и `docker compose version`.
3. При первом запуске проверьте интернет и свободное место: Docker должен скачать зависимости и собрать образ.
4. Убедитесь, что порт `38000` не занят другой установкой Flow2API или другим сервисом.
5. Нажмите **Повторить** в приложении после устранения причины.

Не запускайте второй backend на том же порту. Если используется старая независимая установка Flow2API, сначала разберитесь, как остановить именно ее; не удаляйте все Docker-контейнеры или тома ради сброса приложения.

## Фоновый браузер Omni 1.2 не готов

Для обычных Omni 1.2 Flash `text` и `ingredients` приложение выбирает фоновый браузер автоматически. Это отдельный профиль Flow Studio, а не окно вашего обычного Chrome. Проверка — **Настройки → Фоновая генерация → Проверить фоновый браузер** или `flow_studio_inspect_isolated_browser` с известным `accountId`. Она не загружает изображения и не создает видео.

| Код или состояние | Действие |
| --- | --- |
| `browserReady:false`, `PROFILE_REQUIRED` | Один раз нажмите **Войти заново** у нужного аккаунта, войдите под тем же адресом и подтвердите вход. Подключения только через расширение недостаточно |
| `PROFILE_IN_USE` | Завершите другой процесс, использующий этот управляемый профиль, и повторите проверку без генерации |
| `ACCOUNT_MISMATCH`, `ACCOUNT_CHANGED` | Переподключите выбранный адрес; не переключайтесь на другой аккаунт автоматически |
| `FLOW_LOGIN_REQUIRED`, `FLOW_VERIFICATION_REQUIRED` | Откройте вход через Flow Studio и завершите проверку Google вручную |
| `FLOW_PROJECT_REQUIRED` | Создайте проект Flow в окне входа, затем проверьте фоновый браузер |
| `BROWSER_DRAFT_PRESENT` | В профиле есть посторонний незавершенный запрос. Откройте Flow через подключение аккаунта и сохраните или очистите этот черновик |
| `PRODUCT_ANNOUNCEMENT_NOT_VERIFIED` | Окно новостей отличается от распознанного или содержит другие действия. Проверьте его вручную через подключение аккаунта; условия и согласия подтверждает только пользователь |
| `RESULT_LOST`, `RESULT_INPUT_MISMATCH`, ошибка загрузки после отправки | Сначала найдите принятую задачу в Flow; неизвестный исход не разрешает новую отправку |

`FLOW_UI_TIMEOUT` на этапах `account-button` или `composer-ready` до отправки может быть вызван окном новостей Flow или раскрытой пустой панелью Agent, в том числе за пределами области просмотра. Приложение закрывает только распознанное окно «Introducing Omni 1.2!» с кнопками «View all changelogs» и «Get started», без условий и полей согласия, а также однозначно найденную пустую панель Agent. Текст и вложения сохраняются: непустая панель останавливает подготовку с `BROWSER_DRAFT_PRESENT`. Эти действия не запускают генерацию и не принимают условия Google. Если ошибка остается, проверьте тот же аккаунт через фоновую диагностику без загрузки и генерации; автоматически повторять платный запрос не нужно.

Разрешения macOS «Универсальный доступ» и «Запись экрана» относятся к прежней диагностике обычного Chrome. Для автоматического фонового режима они не нужны. Ошибка браузера не переключает запрос на сервер и не меняет аккаунт. Frames, редактирование, продолжение и другие модели используют маршрут из каталога `generationEngine`.

При первой загрузке Google может показать «Rights to use this image» — подтверждение прав на изображение. Flow Studio покажет текст Google и адрес аккаунта в своем диалоге. Подтверждает пользователь; отмена останавливает загрузку. Приложение не принимает эти условия автоматически, а согласие на загрузку не запускает генерацию и не разрешает расход кредитов.

`INGREDIENT_NOT_VERIFIED` на этапе проверки загруженного изображения означает, что Flow Studio не подтвердил предпросмотр или вложение. Программа ждёт, пока Flow покажет загруженное изображение выбранного файла, и останавливается до генерации, если проверка не прошла. Для диагностики используйте тот же аккаунт, режим и файл. В MCP проверка браузера с `checkBrowser:true` готовит черновик и проверяет вложение без отправки генерации.

Текущая фоновая реализация Omni 1.2 Edit требует точного размера исходника под выбранные формат и разрешение: 360×640 или 640×360 для 360p; 720×1280 или 1280×720 для standard (720p). Несовпадение отклоняется до загрузки: приложение не изменяет размер исходника и не подменяет модель. В установленном приложении проверен непрерывный проход Omni 1.2 Edit через Flow Agent с исходным видео и двумя разными изображениями в точном порядке: полный исходный запрос, одно предложение, одно Approve за 36 кредитов, ожидание, проверка History, скачивание и сохранение без ручного восстановления. Задача завершилась за 279 секунд; MP4 — 720×1280, 9:16, H.264/AAC, 10,026667 секунды. Отдельно проверены задачи без дополнительных изображений и с двумя изображениями, восстановленные по записям отправки без новой генерации. Отдельно в установленном приложении проверен портретный Omni 1.2 Edit 360p без дополнительных изображений: одно предложение, одно Approve за 4 кредита, ожидание, скачивание и сохранение исходного MP4 360×640, H.264/AAC, 24 кадра/с, 3,029333 секунды. Задача завершилась за 219 секунд; размеры и длительность исходника сохранены. Эти проверки покрывают указанные сценарии; Edit 360p с изображениями, другие форматы и длительности не заявлены проверенными. Google может запросить отдельное согласие на права исходного видео; оно не запускает генерацию. Скачанный Edit должен совпадать с исходником по точным размерам и длительности с допуском 0,15 секунды. При размере результата свыше 100 МиБ или недоступной проверке возвращается `OUTPUT_METADATA_UNAVAILABLE`, при несовпадении — `MODEL_SETTINGS_NOT_VERIFIED`; неизвестный исход нельзя автоматически повторять.

Для поддерживаемых ошибок наблюдения после отправки приложение освобождает браузер и один раз продолжает чтение той же задачи по приватной записи отправки. Для Agent дополнительно сверяются аккаунт, проект, модель, полный запрос, исходная сцена и порядок изображений. Отмена, подтвержденный отказ или несовпадение записи блокируют этот переход. Восстановление не загружает исходники, не создает предложение или новую задачу и не нажимает Approve; нового расхода кредитов нет. Повторная ошибка наблюдения сохраняет неизвестный исход.

## Новое видео остановлено из-за видимой метки

Новые видео по умолчанию создаются **с меткой**. Режим **«Только без метки»** доступен через готовые аккаунты, на которых можно выключить `Visible watermarking`. Flow Studio хранит результат проверки каждого аккаунта и сверяет выбранный режим до загрузки исходников и перед отправкой. Список возможностей можно обновить через проверку подключений в разделе «Аккаунты».

| Код | Что подтверждено и что делать |
| --- | --- |
| `VISIBLE_WATERMARK_REQUIRED` | Google явно требует видимую метку для этого аккаунта. Наблюденный официальный текст: `Visible watermarking is required in your region`. Не трактуйте его как свойство всех аккаунтов или регионов; приложение не меняет регион и не ротирует аккаунты |
| `VISIBLE_WATERMARK_UNVERIFIED` | Приложение не смогло подтвердить выбранный режим метки. Проверьте подключение и настройку того же аккаунта |
| `VISIBLE_WATERMARK_ACCOUNT_UNAVAILABLE` | Среди готовых аккаунтов нет проверенного варианта для режима «Только без метки». Проверьте включённые аккаунты или выберите «С меткой» |
| `VISIBLE_WATERMARK_ROUTE_UNVERIFIED` | Серверный или прежний диагностический видеомаршрут не может проверить выбранный режим метки. Запрос остановлен до отправки |

`prepare_generation` проверяет выбранный режим метки в браузере только при `checkBrowser:true`. Такая проверка может изменить официальный переключатель, который действует на весь Google-аккаунт. Проверка подключения аккаунта только считывает статус переключателя. Просмотр, скачивание и восстановление прежних результатов используют уже созданные файлы.

## Вход не подтверждается или возвращается 401

1. В карточке ошибки нажмите **Войти в Google заново** или откройте **Аккаунты → Войти заново** у нужного аккаунта.
2. Войдите в тот же Google-аккаунт и откройте Flow. При переподключении другой адрес не подойдет.
3. Вернитесь в приложение и выполните показанное действие: **Я вошёл** для управляемого профиля или **Проверить подключение** для аккаунта из расширения.
4. Дождитесь подтверждения. Если проверка не прошла, раскройте **Причина ошибки**; код ошибки генерации находится в **Технических деталях**.
5. Проверьте результат предыдущей задачи в Flow. Запускайте новую генерацию только после этого.

Повторный вход сохраняет текущий текст, модель и исходные данные в редакторе, но не повторяет генерацию. Пароль, Touch ID и другие проверки Google пользователь подтверждает сам в браузере.

## Модель есть, но генерация недоступна

Каталог описывает настроенные модели. Он не подтверждает доступ Google-аккаунта, баланс, региональные условия или текущую работу сервиса. Обновите баланс, проверьте тот же аккаунт в Google Flow и прочитайте исходное сообщение ошибки. Не считайте автоматическую смену модели безопасным повтором: это другой запрос с возможным новым списанием.

## Google вернул PUBLIC_ERROR_MINOR

Это явный отказ Google, а не ошибка авторизации `401`. Если код пришел после запуска задачи, она могла пройти загрузку исходников и завершиться отказом при обработке.

Точная расшифровка этого кода не приведена в публичной справке Flow. Возможна возрастная проверка содержимого, но по одному `PUBLIC_ERROR_MINOR` нельзя установить, какой текст, референс или кадр вызвал отказ, или утверждать возраст человека на исходнике. Google отдельно указывает, что редактирование загруженных видео с узнаваемыми несовершеннолетними не поддерживается: [ограничения Flow](https://support.google.com/flow/answer/16353544?hl=ru).

Откройте карточку той же задачи в веб-версии Flow под аккаунтом, который ее отправил, и прочитайте подробное сообщение. Сам по себе этот код не требует повторного входа или смены аккаунта. Не запускайте одинаковый запрос автоматически. `PUBLIC_ERROR_USER_MINOR` — другой код; не смешивайте его с `PUBLIC_ERROR_MINOR`.

## В браузере работает, а Flow Studio возвращает PUBLIC_ERROR_UNUSUAL_ACTIVITY

Код подтверждает отказ конкретной отправки при проверке активности. Он сам по себе не доказывает блокировку аккаунта, нехватку кредитов или необходимость повторного входа. Сохраните `rpc=...`, ID модели и аккаунт из карточки результата. Успешный ответ внешнего сервиса проверки также не подтверждает, что Google принял генерацию.

Старый серверный маршрут получил этот отказ и после исправления непрерывности cookies. Omni 1.2 text, ingredients и frames теперь отправляются через отдельный фоновый браузер, но смена реализации, успешная проверка входа или подготовка сами по себе не подтверждают принятие платной генерации Google.

Если обычный Flow под тем же аккаунтом работает, сравнивайте способ отправки и непрерывность сессии. Локальный КД останавливает новые отказы, но не исправляет несовместимость отправки. Не повышайте число повторов и не переключайте аккаунты автоматически для такой проверки.

## Аккаунт остывает после ошибки

Над результатом и в истории указан аккаунт отправки; в **Аккаунтах → Последняя ошибка генерации** — последняя причина и время. Ошибка аккаунта или сервиса при его использовании включает локальный КД на 30 минут. Таймер переживает перезапуск; после его окончания аккаунт снова участвует в выборе для новых запросов.

**Сбросить КД** снимает только локальную паузу, сохраняя ручное отключение аккаунта. Это не подтверждает снятие ограничений Google. Для `PUBLIC_ERROR_UNUSUAL_ACTIVITY` также доступен явный ручной сброс локального таймера. Он не меняет решение Google и не запускает повторный запрос. Ни окончание КД, ни сброс не повторяют запрос автоматически.

**Повторить генерацию** использует сохранённые исходники и тот же аккаунт. Кнопка объясняет недоступность повтора: КД, отсутствие исходников, недоступный аккаунт или неизвестный исход предыдущей отправки. Отменённую или прерванную задачу сначала найдите в Flow, чтобы исключить двойное списание.

## Долго нет результата

Проверьте статус задачи. В фоновом режиме браузер принадлежит приложению: не закрывайте Flow Studio до результата. Видео может готовиться долго. Тайм-аут MCP касается ожидания ответа, а не обязательно самой генерации. Прочитайте `flow_studio_get_job` или `flow_studio_list_jobs` перед повтором.

Если приложение закрылось или локальное ожидание отменено, проверьте Flow. Задача у Google могла продолжиться. Новый запуск может повторно расходовать кредиты.

## Стандартные изображения и исходное видео

Фоновая реализация изображений сопоставляет только стандартное качество Nano Banana 2.1, Nano Banana 2 Lite и Nano Banana Pro и пять точных форматов каталога. Не подменяйте 2K/4K стандартным результатом: для Nano Banana 2.1 и Pro приложение выбирает явный upscale при скачивании; Lite поддерживает только стандартный вариант. Проверено скачивание существующего портретного Nano Banana 2.1 через 2K Upscaled: 1536×2752 против стандартного 768×1376, без новой генерации. Другие семейства, форматы и 4K еще не проверены. Проверены фактические результаты с двумя разными референсами (JPG 768×1376) и без референсов (1024×1024); это не подтверждает все семейства или варианты качества.

При загрузке исходного видео Google может запросить отдельные «Rights to use this video». Согласие на платную генерацию не заменяет подтверждение этих условий. До явного ответа пользователя приложение не принимает их. Пройденная загрузка или появившийся запрос согласия не доказывают успешное редактирование видео.

Отсутствующая, неоднозначная или изменившаяся связь отклоняется. Этот путь проверен без новой генерации на изображении с двумя референсами, Veo 720p и восстановлении исходной задачи по записи отправки. Отдельно в установленном приложении проверен портретный Omni 1.2 Edit 360p без дополнительных изображений: одно предложение, одно Approve за 4 кредита, ожидание, скачивание и сохранение исходного MP4 360×640, H.264/AAC, 24 кадра/с, 3,029333 секунды. Не запускайте генерацию заново. Для фоновой задачи нажмите **Проверить результат в Flow** или используйте `flow_studio_recover_job` с прежним `jobId`. Восстановление читает сохраненную отправку и сравнивает доступный текст History, упорядоченные ингредиенты и постер в деталях. Изображения в истории Flow могут подгружаться позже текста; приложение ожидает их готовность перед проверкой. После подтверждения оно скачивает исходный размер через штатную кнопку Flow и обновляет ту же задачу.

Восстановление прежней оплаченной задачи с одним референсом проверено в установленном приложении: получен и сохранен портретный MP4 720×1280 с H.264/AAC, около 10 секунд. Это подтверждает восстановление и скачивание этой задачи, а не все варианты модели или непрерывную обработку новой генерации.

## Не загружается предпросмотр

Попробуйте **Сохранить как…** у результата. Ошибка предпросмотра не равна ошибке генерации. Если сохранение тоже не работает, сохраните текст ошибки и проверьте сеть. Кэш не заменяет отдельное сохранение важных файлов.

## MCP не видит приложение

1. Проверьте Node.js: `node --version`; нужен 22 или новее.
2. При запуске из исходников выполните `npm ci --prefix app`.
3. Проверьте абсолютный путь к `mcp-server.cjs`. Если клиент не находит `node`, укажите абсолютный путь к нему.
4. Откройте Flow Studio вручную, дождитесь подключения и повторите `flow_studio_status`.
5. Если меняли конфигурацию, переподключите MCP-сервер в своем клиенте.

| Код | Что проверить |
| --- | --- |
| `APP_LAUNCH_FAILED` | Приложение установлено и открывается вручную |
| `APP_UNAVAILABLE` | Автозапуск desktop-приложения доступен на macOS |
| `BRIDGE_UNAVAILABLE` | Приложение запущено; первый запуск движка завершен |
| `BRIDGE_TIMEOUT`, `BRIDGE_TRANSPORT` | Состояние приложения и уже принятой задачи перед повтором |
| `BRIDGE_UNSAFE` | Файл моста принадлежит текущему пользователю и имеет ожидаемые права; не ослабляйте проверку через `chmod 777` |
| `INVALID_ARGUMENTS` | Точный ID модели, абсолютные пути и подходящий тип входных данных |

Не отправляйте содержимое `agent-bridge.json`: в нем находится секрет локального моста.

## Что включить в issue

- Версию Flow Studio, macOS и архитектуру Mac.
- Docker Desktop или Colima, а также версии Docker и Docker Compose.
- Действия до ошибки, ожидаемый и фактический результат.
- Текст ошибки и технический код, без секретов.
- ID модели и тип входа: текст, образцы, кадры или продолжение.
