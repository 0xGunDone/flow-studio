# Диагностика

[← README](../README.md)

## Движок не запускается

1. Прочитайте сообщение запуска в приложении.
2. Убедитесь, что запущен Docker Desktop или Colima, затем проверьте `docker info` и `docker compose version`.
3. При первом запуске проверьте интернет и свободное место: Docker должен скачать зависимости и собрать образ.
4. Убедитесь, что порт `38000` не занят другой установкой Flow2API или другим сервисом.
5. Нажмите **Повторить** в приложении после устранения причины.

Не запускайте второй backend на том же порту. Если используется старая независимая установка Flow2API, сначала разберитесь, как остановить именно ее; не удаляйте все Docker-контейнеры или тома ради сброса приложения.

## Вход не подтверждается или возвращается 401

1. В карточке ошибки нажмите **Войти в Google заново** или откройте **Аккаунты → Войти заново** у нужного аккаунта.
2. Войдите в тот же Google-аккаунт и откройте Flow. При переподключении другой адрес не подойдет.
3. Вернитесь в приложение и выполните показанное действие: **Я вошёл** для управляемого профиля или **Проверить подключение** для аккаунта из расширения.
4. Дождитесь подтверждения. Если проверка не прошла, раскройте **Причина ошибки**; код ошибки генерации находится в **Технических деталях**.
5. Проверьте результат предыдущей задачи в Flow. Запускайте новую генерацию только после этого.

Повторный вход сохраняет текущий текст, модель и исходные данные в редакторе, но не повторяет генерацию. Пароль, Touch ID и другие проверки Google пользователь подтверждает сам в браузере.

## Модель есть, но генерация недоступна

Каталог описывает настроенные модели. Он не подтверждает доступ Google-аккаунта, баланс, региональные условия или текущую работу сервиса. Обновите баланс, проверьте тот же аккаунт в Google Flow и прочитайте исходное сообщение ошибки. Не считайте автоматическую смену модели безопасным повтором: это другой запрос с возможным новым списанием.

## Долго нет результата

Проверьте статус задачи. Видео может готовиться долго. Тайм-аут MCP касается ожидания ответа, а не обязательно самой генерации. Прочитайте `flow_studio_get_job` или `flow_studio_list_jobs` перед повтором.

Если приложение закрылось или локальное ожидание отменено, проверьте Flow. Задача у Google могла продолжиться. Новый запуск может повторно расходовать кредиты.

## Не загружается предпросмотр

Попробуйте **Сохранить как…** у результата. Ошибка предпросмотра не равна ошибке генерации. Если сохранение тоже не работает, сохраните текст ошибки и проверьте сеть. Кэш не заменяет отдельное сохранение важных файлов.

## MCP не видит приложение

1. Проверьте Node.js: `node --version`; нужен 22 или новее.
2. При запуске из исходников выполните `npm ci --prefix app`.
3. Проверьте абсолютный путь к `mcp-server.cjs`. Если клиент не находит `node`, укажите абсолютный путь к нему.
4. Откройте Flow Studio вручную, дождитесь подключения и повторите `flow_studio_status`.
5. Если меняли конфигурацию, переподключите MCP-сервер в своем клиенте.

| Код | Что проверить |
| --- | --- |
| `APP_LAUNCH_FAILED` | Приложение установлено и открывается вручную |
| `APP_UNAVAILABLE` | Автозапуск desktop-приложения доступен на macOS |
| `BRIDGE_UNAVAILABLE` | Приложение запущено; первый запуск движка завершен |
| `BRIDGE_TIMEOUT`, `BRIDGE_TRANSPORT` | Состояние приложения и уже принятой задачи перед повтором |
| `BRIDGE_UNSAFE` | Файл моста принадлежит текущему пользователю и имеет ожидаемые права; не ослабляйте проверку через `chmod 777` |
| `INVALID_ARGUMENTS` | Точный ID модели, абсолютные пути и подходящий тип входных данных |

Не отправляйте содержимое `agent-bridge.json`: в нем находится секрет локального моста.

## Что включить в issue

- Версию Flow Studio, macOS и архитектуру Mac.
- Docker Desktop или Colima, а также версии Docker и Docker Compose.
- Действия до ошибки, ожидаемый и фактический результат.
- Текст ошибки и технический код, без секретов.
- ID модели и тип входа: текст, образцы, кадры или продолжение.

Перед публикацией удалите из логов и снимков cookies, токены, API-ключи, адреса аккаунтов, личные запросы и локальные пути. Не прикладывайте базу данных, профили Chrome или папку `Application Support/Flow Studio` целиком. Для уязвимостей используйте [SECURITY.md](../SECURITY.md).
