# Flow Studio 1.2.1 — Управление аккаунтами

- Тумблер «Включён / Выключен» у каждого аккаунта. Ручное отключение сохраняется при обновлении сессии, переподключении и автоматическом восстановлении.
- «Удалить» с подтверждением адреса. Удаляется локальное подключение; Google-аккаунт, профиль Chrome, история и файлы остаются. Фоновая синхронизация не добавит подключение обратно.
- «Проверить все включённые»: последовательная проверка только активных аккаунтов, прогресс, итог и отдельная причина ошибки. Сбой одного аккаунта не останавливает остальные. Генерация и расход кредитов на создание результата не запускаются.
- Удаление блокируется во время генерации. Завершение приложения дожидается сохранения удаления.

Omni 1.2 остаётся предпочтительной для новых видео без явного выбора. Обновлены встроенная справка и инструкция.

Сборки Alpha для Apple Silicon и Intel используют локальную подпись без Apple Developer ID и нотарификации. Нужны Google Chrome и Docker Desktop либо Colima с Docker CLI и Docker Compose.
