# Flow Studio 1.0.0 — Alpha

Первый публичный выпуск приложения для macOS: изображения и видео Google Flow, несколько аккаунтов, референсы и кадры, история, сохранение файлов и MCP.

## Скачать

| Файл | Для кого |
| --- | --- |
| `Flow-Studio-1.0.0-mac-arm64.dmg` или `.zip` | Mac с Apple Silicon |
| `Flow-Studio-1.0.0-mac-x64.dmg` или `.zip` | Mac с процессором Intel |
| `Flow-Studio-1.0.0-mcp.zip` | Отдельный MCP-адаптер; после распаковки выполните `npm ci` |
| `Flow-Studio-1.0.0-extension.zip` | Необязательное расширение для существующих профилей Chrome |
| `SHA256SUMS.txt` | Контрольные суммы файлов |

## Установка

1. Установите Google Chrome и Docker Desktop либо Colima с Docker CLI и Compose.
2. Перенесите приложение из DMG или ZIP в `Applications`.
3. Запустите Docker и Flow Studio. Первый запуск собирает локальный движок; нужен интернет.
4. Добавьте аккаунт в разделе «Аккаунты». Google-пароли и подтверждения вводятся только в Chrome.

Сборки имеют ad-hoc подпись, но **не подписаны Apple Developer ID и не нотарифицированы**. macOS может запросить разрешение на запуск. Используйте только штатный механизм macOS для приложения, которому доверяете; не отключайте защиту системы целиком.

## Что проверено

- 59 тестов приложения/MCP и 7 тестов расширения прошли.
- Выбранные тесты backend проверили сессии, импорт аккаунтов, транспорт, получение видео, модели и обработку ошибок.
- Чистый первый запуск backend в отдельном контейнере: случайные локальные учетные данные, 0 аккаунтов, 82 модели, отказ `401` при анонимном чтении аккаунтов.
- Отдельный MCP-архив: установка по lockfile и обнаружение 13 инструментов.
- Обе архитектуры упакованы; проверены архитектура исполняемого файла, ad-hoc подпись, состав и лицензии.

Intel-сборка создана на Apple Silicon; работа на физическом Intel Mac отдельно не проверялась. Автотесты не подтверждают доступ Google-аккаунта ко всем моделям. Платную генерацию для проверки публичного выпуска не запускали.

## Ограничения

Google Flow использует изменяемые веб-интерфейсы. Повторный вход, доступность моделей, квоты и условия Google остаются вне контроля приложения. Проект независим от Google.

Готовое приложение содержит исходники движка, но не Docker, Chrome и заранее собранный Docker-образ. Первый запуск не является полностью автономной установкой без интернета.

Исходники и сборки не содержат аккаунтов разработчика, сессий Google, истории генераций или локальной базы данных.
