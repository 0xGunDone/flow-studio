# Первый запуск

[← README](../README.md)

## Подготовка Mac

Установите Google Chrome в стандартную папку `/Applications`. Для движка выберите Docker Desktop либо Colima с Docker CLI и Docker Compose. Готовое приложение содержит исходники backend, но не включает Docker, Chrome и готовый Docker-образ.

Проверьте, что Docker запущен:

```bash
docker info
docker compose version
```

При использовании Colima сначала выполните:

```bash
colima start
```

Первый запуск требует интернет: Docker загружает базовый образ и зависимости. Следующие запуски используют локальный образ. Скорость зависит от сети и Mac.

## Установка приложения

1. Откройте [Releases](https://github.com/0xGunDone/flow-studio/releases/tag/v1.0.0).
2. Выберите `arm64`, если в «Об этом Mac» указан чип Apple, или `x64`, если указан процессор Intel.
3. Распакуйте ZIP или откройте DMG и перенесите `Flow Studio.app` в `Applications`.
4. Запустите приложение и дождитесь подключения движка. Локальный API-ключ и пароль создаются автоматически; вводить их в интерфейс не нужно.

### Если macOS блокирует запуск

Сборки не подписаны сертификатом Apple Developer ID и не нотарифицированы. Скачивайте их только со страницы релизов проекта и сверяйте контрольную сумму, если она приложена к релизу. Разрешайте запуск только сборки, которой доверяете.

1. Попробуйте открыть `Flow Studio.app` обычным способом.
2. Если macOS заблокировала приложение, откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Найдите сообщение о Flow Studio и используйте **Всё равно открыть**, если эта возможность доступна. Подтвердите действие штатным диалогом macOS.

Названия пунктов зависят от версии macOS и языка системы. Не отключайте Gatekeeper для всей системы. Если нужного действия нет, проверьте источник файла и сообщение macOS перед дальнейшими действиями.

## Подключение Google

1. В Flow Studio откройте **Аккаунты → Войти в Google**.
2. В открывшемся Chrome войдите в нужный Google-аккаунт и откройте Flow. Если Google запрашивает подтверждение входа, завершите его в браузере.
3. Вернитесь в приложение и нажмите **Я вошёл**.
4. Дождитесь сообщения о подключении. Для следующего аккаунта повторите эти действия.

Пароль и коды подтверждения вводятся только на странице Google. Flow Studio сохраняет сессию, необходимую для запросов. Для каждого нового аккаунта приложение создает отдельный профиль Chrome. Обычный вход через приложение не требует расширения.

После подтверждения входа окно Chrome можно закрыть. Для обновления сессии приложение может кратко запускать Chrome в фоне. Если Google снова требует интерактивный вход, выберите **Войти заново** у аккаунта. Автоматическое обновление не отменяет требования Google к повторной авторизации.

**Обновить** запрашивает список и баланс. **Проверить подключение** отдельно проверяет сессию. Включенный аккаунт, видимый баланс и успешная проверка не гарантируют доступ ко всем моделям.

## Первая генерация

1. Откройте **Создать** и выберите **Изображение** или **Видео**.
2. Выберите модель и прочитайте ее ограничения. Формат кадра, длительность и разрешение входят в вариант модели.
3. Введите запрос. При необходимости добавьте исходные изображения по таблице ниже.
4. Нажмите кнопку генерации или `⌘ Enter` из поля запроса. Приложение выполняет одну задачу за раз.
5. Дождитесь результата, нажмите **Сохранить как…** и выберите файл. Кнопка **Открыть папку** показывает сохраненный результат в Finder.

| Сценарий | Исходные данные |
| --- | --- |
| Изображение по тексту | Только запрос |
| Изображение по референсам / редактирование | До пяти изображений, в пределах лимита модели |
| Видео по тексту | Только запрос и текстовая видеомодель |
| Видео «По образцам» | До трех изображений, в пределах лимита модели; они не задают границы ролика |
| Видео «По кадрам» | Сначала начальный, затем конечный кадр, если модель его принимает или требует |
| Продолжение видео | ID существующего видео Google Flow; локальный видеофайл и ID задачи Flow Studio не подходят |

Поддерживаемые изображения: PNG, JPEG, WebP и GIF, до 20 МБ на файл. Для порядка кадров проверьте подписи под миниатюрами. Чтобы изменить порядок, удалите исходники и добавьте заново.

## История и выход

История сохраняет последние 100 задач. Кнопка **Использовать запрос** возвращает текст и доступную модель в редактор; исходные изображения и ID видео нужно добавить снова. Она не запускает генерацию.

Сохраняйте важные результаты отдельно. История и локальный кэш не заменяют экспорт и резервную копию.

Во время генерации закрытие окна предлагает продолжить работу в фоне. Полный выход из приложения прекращает ожидание. После повторного запуска незавершенная локальная задача отмечается ошибкой, хотя Google мог продолжить ее выполнение. Проверьте Flow перед новым запуском.

## Где хранятся данные

```text
~/Library/Application Support/Flow Studio
```

Здесь находятся история, рабочие файлы, профили Chrome и данные локального движка. Папка содержит данные авторизации. Не переносите ее в публичный репозиторий и не отправляйте целиком при диагностике. Удаление приложения само по себе не является удалением этих данных.

## Дополнительное расширение

Каталог [`extension/`](../extension) содержит расширение для синхронизации сессии из обычного Chrome в Flow2API. Это дополнительный путь для пользователей существующей установки Flow2API. Для нового desktop-приложения используйте встроенный вход; установка расширения и ручная настройка токенов не требуются.

Аккаунтам, подключенным только через расширение, нужен работающий Chrome для автоматической синхронизации. [Инструкция расширения](../extension/README.md) относится к этому отдельному сценарию.
