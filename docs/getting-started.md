# Первый запуск

[← README](../README.md)

## Подготовка Mac

Установите Google Chrome в стандартную папку `/Applications`. Для движка выберите Docker Desktop либо Colima с Docker CLI и Docker Compose. Готовое приложение содержит исходники backend, но не включает Docker, Chrome и готовый Docker-образ.

Проверьте, что Docker запущен:

```bash
docker info
docker compose version
```

При использовании Colima сначала выполните:

```bash
colima start
```

Первый запуск требует интернет: Docker загружает базовый образ и зависимости, включая `ffprobe` для проверки видео. Устанавливать FFmpeg на Mac не нужно. Следующие запуски используют локальный образ. Скорость зависит от сети и Mac.

## Установка приложения

1. Откройте [Releases](https://github.com/0xGunDone/flow-studio/releases).
2. Выберите `arm64`, если в «Об этом Mac» указан чип Apple, или `x64`, если указан процессор Intel.
3. Распакуйте ZIP или откройте DMG и перенесите `Flow Studio.app` в `Applications`.
4. Запустите приложение и дождитесь подключения движка. Локальный API-ключ и пароль создаются автоматически; вводить их в интерфейс не нужно.

### Если macOS блокирует запуск

Сборки не подписаны сертификатом Apple Developer ID и не нотарифицированы. Скачивайте их только со страницы релизов проекта и сверяйте контрольную сумму, если она приложена к релизу. Разрешайте запуск только сборки, которой доверяете.

1. Попробуйте открыть `Flow Studio.app` обычным способом.
2. Если macOS заблокировала приложение, откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Найдите сообщение о Flow Studio и используйте **Всё равно открыть**, если эта возможность доступна. Подтвердите действие штатным диалогом macOS.

Названия пунктов зависят от версии macOS и языка системы. Не отключайте Gatekeeper для всей системы. Если нужного действия нет, проверьте источник файла и сообщение macOS перед дальнейшими действиями.

## Подключение Google

1. В Flow Studio откройте **Аккаунты → Войти в Google**.
2. В открывшемся Chrome войдите в нужный Google-аккаунт и откройте Flow. Если Google запрашивает подтверждение входа, завершите его в браузере.
3. Вернитесь в приложение и нажмите **Я вошёл**.
4. Дождитесь сообщения о подключении. Для следующего аккаунта повторите эти действия.

Пароль и коды подтверждения вводятся только на странице Google. Flow Studio сохраняет сессию, необходимую для запросов. Для каждого нового аккаунта приложение создает отдельный профиль Chrome. Обычный вход через приложение не требует расширения.

После подтверждения входа окно Chrome можно закрыть. Для обновления сессии приложение может кратко запускать Chrome в фоне. Если Google снова требует интерактивный вход, выберите **Войти заново** у аккаунта. Автоматическое обновление не отменяет требования Google к повторной авторизации.

**Тумблер** в карточке включает или отключает аккаунт для новых генераций; обновление сессии сохраняет ручное отключение. **Проверить все включённые** последовательно проверяет активные аккаунты, показывает прогресс и отдельные ошибки, пропускает выключенные. **Удалить** требует подтверждения и убирает подключение из приложения; Google-аккаунт, профиль Chrome, сохранённые результаты и история остаются.

**Обновить** запрашивает список и баланс. **Проверить подключение** отдельно проверяет сессию. Включенный аккаунт, видимый баланс и успешная проверка не гарантируют доступ ко всем моделям.

## Фоновая генерация Omni 1.2 Flash

Модели Omni 1.2 Flash с методами **Текст → видео**, **Ingredients · Ингредиенты** и **Frames · Кадры** автоматически используют отдельный браузер Flow Studio. В нем приложение готовит запрос, загружает до семи изображений, отправляет задачу один раз, ожидает видео и сохраняет результат в общую историю. Можно работать в своем обычном Chrome; доступы macOS «Универсальный доступ» и «Запись экрана» для этого режима не нужны.

Нужен профиль, подключенный через Flow Studio. Если у аккаунта указано, что нужен вход для фоновой генерации, один раз нажмите **Войти заново**, войдите под тем же адресом и подтвердите **Я вошёл**. После этого профиль сохраняется. Аккаунта, подключенного только через расширение, для этого режима недостаточно.

Откройте **Настройки → Фоновая генерация**, выберите аккаунт и нажмите **Проверить фоновый браузер**. Проверка читает аккаунт и проект, не загружает исходники и не создает видео. Если в Flow еще нет проекта, создайте его в окне входа и повторите проверку.

При первой загрузке Google может показать «Rights to use this image» — подтверждение прав на изображение. Flow Studio покажет текст Google и адрес аккаунта в своем диалоге. Подтверждает пользователь; отмена останавливает загрузку. Приложение не принимает эти условия автоматически, а согласие на загрузку не запускает генерацию и не разрешает расход кредитов.

Для Frames заполняйте отдельные области начального и конечного кадра. Они не становятся ингредиентами и сохраняют роли при отправке. Генерация с двумя кадрами на Omni 1.2, 3 секунды, портрет, 360p проверена до скачивания и сохранения MP4. Возможности других длительностей берите из текущего каталога.

В редакторе можно выбрать аккаунт или оставить **Автоматически**. Выбранный аккаунт фиксируется для задачи; после ошибки приложение не меняет его и не отправляет запрос другим движком. Omni 1.2 Edit подключен к фоновому браузеру; связь исходного видео с записью результата и фактический вывод еще проходят живую проверку. Продолжение и неподдерживаемые варианты сохраняют серверный маршрут.

## Первая генерация

1. Откройте **Создать** и выберите **Изображение** или **Видео**.
2. Для видео сначала выберите **Режим видео**: текст, **Frames · Кадры**, **Ingredients · Ингредиенты**, редактирование или продолжение. Затем выберите **Модель**, **Длительность** и **Формат**. **Разрешение** появляется, когда каталог предлагает несколько вариантов. Для изображения выберите модель, формат и доступное разрешение.
3. Введите запрос и добавьте исходники, если они нужны. В режиме **Frames · Кадры** перетащите изображение в отдельную область **Начальный кадр** или **Конечный кадр** либо нажмите **Добавить** в нужной области. Для ингредиентов и изображений используйте общий список файлов: перетаскивание из Finder или выбор кнопкой.
4. Нажмите кнопку генерации или `⌘ Enter` из поля запроса. Приложение выполняет одну задачу за раз.
5. Дождитесь результата, нажмите **Сохранить как…** и выберите файл. Кнопка **Открыть папку** показывает сохраненный результат в Finder.

| Сценарий | Исходные данные |
| --- | --- |
| Изображение по тексту | Только запрос |
| Изображение по референсам / редактирование | До пяти изображений, в пределах лимита модели |
| Видео «Текст → видео» | Только запрос |
| Veo «Ingredients · Ингредиенты» | От одного до трех изображений для содержания или стиля; они не задают границы ролика |
| Omni «Ingredients · Ингредиенты» | До семи изображений |
| Omni «Редактирование» | Одно исходное видео и до пяти изображений для содержания или стиля |
| Видео «Frames · Кадры» | Начальный кадр в своей области и необязательный конечный кадр в соседней; лимиты указаны для выбранной модели |
| Продолжение видео | ID существующего видео Google Flow; локальный видеофайл и ID задачи Flow Studio не подходят |

Поддерживаемые изображения: PNG, JPEG, WebP и GIF, до 20 МБ на файл. Для Omni Edit выберите **Добавить фото или видео**: видео должно быть в MP4, MOV или M4V до 100 МиБ. Omni 1.2 Edit принимает до 15 секунд, Omni 1.1 Edit — до 10 секунд. Оно загружается как видео, без извлечения кадров.

Под каждым файлом видны название и тип; видео можно воспроизвести до запуска. Стрелки **←** и **→** меняют порядок ингредиентов, **×** удаляет файл. В режиме Frames кнопки **Заменить** и **Удалить** действуют на отдельный кадр. Конечный кадр без начального не запускает генерацию. Файлы для кадров и ингредиентов хранятся раздельно при смене режима; в запрос попадают исходники выбранного режима.

Списки настроек содержат только сочетания из текущего каталога. В нем Veo Frames есть у Lite, Fast и Quality на 4, 6 и 8 секунд; Veo Ingredients — у Lite и Fast на 8 секунд. Omni 1.2 предлагает текст, ингредиенты и кадры на 3–15 секунд; Omni 1.1 сохраняет варианты на 4, 6, 8 и 10 секунд. Для Omni Edit длительность определяется исходным видео. Для продолжения используется отдельный ID видео из Flow. Доступный стандартный вариант разрешения не означает наличие переключателя на 1080p или 4K.

Варианты Veo на 4 и 6 секунд требуют Google AI Ultra и недоступны на Pro. Для Pro выберите доступную модель на 8 секунд. Наличие сочетания в списках не гарантирует доступ на вашем тарифе. [Официальная таблица возможностей Google](https://support.google.com/flow/answer/16352836) и [руководство по кадрам и образцам](https://support.google.com/flow/answer/16353334) описывают различия режимов.

Текущая фоновая реализация Omni 1.2 Edit требует точного размера исходника под выбранные формат и разрешение: 360×640 или 640×360 для 360p; 720×1280 или 1280×720 для standard (720p). Несовпадение отклоняется до загрузки: приложение не изменяет размер исходника и не подменяет модель. Связь исходного видео с записью результата и фактический вывод Edit еще не проверены. Google может запросить отдельное согласие на права исходного видео; оно не запускает генерацию.

## История и выход

Проверка результата использует одну выбранную семантическую запись History: полный текст запроса сравнивается точно, порядок референсов и постер берутся из той же записи. Перед скачиванием эти поля повторно проверяются, а меню открывается только через собственную кнопку выбранной записи и ее aria-controls. Отсутствующая, неоднозначная или изменившаяся связь отклоняется. Этот путь проверен без новой генерации на изображении с двумя референсами, Veo 720p и восстановлении исходной задачи по записи отправки. Связь с исходным видео Edit и фактический результат Edit еще не проверены.

История сохраняет последние 100 задач. Карточка результата и история показывают аккаунт, отправивший запрос.

**Повторить генерацию** создаёт новую попытку с исходными текстом, моделью, порядком вложений и ролями кадров на том же аккаунте; текущий редактор на неё не влияет. Повтор может расходовать кредиты. Исходники сохраняются в закрытом локальном кэше для последних 20 задач, суммарно до 512 МиБ. Если исходников уже нет, аккаунт удалён или отключён, результат запроса неизвестен либо Google отклонил содержимое, кнопка недоступна с объяснением. Для старых задач без кэша используйте **Использовать запрос** и добавьте файлы снова; эта кнопка сама ничего не запускает.

После ошибки, связанной с выбранным аккаунтом, он получает локальный КД на 30 минут. В **Аккаунтах** видны таймер, последняя ошибка и **Сбросить КД**. Сброс не включает вручную отключённый аккаунт и не снимает ограничение Google. Ручной сброс доступен для любой ошибки, включая `PUBLIC_ERROR_UNUSUAL_ACTIVITY`; это только локальный таймер, а не снятие ограничения Google. Локальные ошибки подготовки загрузки и отказы проверки содержимого не отправляют аккаунт на КД. Окончание таймера само не запускает генерацию.

Сохраняйте важные результаты отдельно. История и локальный кэш не заменяют экспорт и резервную копию.

Локальный движок работает, пока открыто Flow Studio. Закрытие окна кнопкой × или выход через `⌘Q` завершает приложение и останавливает движок и его фоновый браузер. Свернутое окно оставляет приложение открытым, поэтому генерация продолжается.

Выход во время генерации прекращает локальное ожидание. После повторного запуска незавершенная локальная задача отмечается ошибкой, хотя Google мог продолжить ее выполнение и списать кредиты. Проверьте результат в Flow перед новым запуском.

## Где хранятся данные

```text
~/Library/Application Support/Flow Studio
```

Здесь находятся история, рабочие файлы, профили Chrome и данные локального движка. Папка содержит данные авторизации. Не переносите ее в публичный репозиторий и не отправляйте целиком при диагностике. Удаление приложения само по себе не является удалением этих данных.

## Настройки внешних сервисов

В приложении откройте **Настройки → 2Captcha**. Поле **API-ключ 2Captcha** всегда открывается пустым; сохранённый ключ не показывается. Статус сообщает только, задан ли ключ. Пустое поле не очищает существующее значение, а после успешного сохранения новый ввод удаляется из поля.

Сохранение ключа не меняет выбранный способ проверки и не вызывает внешний сервис. Пока идёт генерация, сохранение недоступно. Ключ не входит в историю, черновики или ответы MCP.

## Дополнительное расширение

Каталог [`extension/`](../extension) содержит расширение для синхронизации сессии из обычного Chrome в Flow2API. Это дополнительный путь для пользователей существующей установки Flow2API. Для нового desktop-приложения используйте встроенный вход; установка расширения и ручная настройка токенов не требуются.

Аккаунтам, подключенным только через расширение, нужен работающий Chrome для автоматической синхронизации. [Инструкция расширения](../extension/README.md) относится к этому отдельному сценарию.
