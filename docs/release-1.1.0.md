# Flow Studio 1.1.0 — Alpha

Выпуск обновляет каталог Veo и добавляет редактирование загруженного видео в Omni.

## Что изменилось

- Ключи Veo приведены к текущему каталогу Google Flow, проверенному 27 октября 2026 года. Варианты на 4 и 6 секунд требуют Google AI Ultra; для Pro выбирайте доступную модель на 8 секунд. Добавлены варианты «По кадрам» на 8 секунд для Lite, Fast и Quality.
- Обычный Omni принимает до 7 изображений. Отдельные модели Omni Edit принимают исходное видео и до 5 изображений.
- Исходное видео загружается целиком, без извлечения кадров. Поддерживаются MP4, MOV и M4V до 10 секунд и 100 МБ.
- Несколько исходных файлов можно выбрать за один раз. В редакторе видны их названия, типы и счетчики; видео можно воспроизвести, порядок — изменить стрелками, файл — удалить. Смена модели сохраняет выбранные файлы и показывает несовместимость перед отправкой.
- Через MCP для Omni Edit передается один путь в `videoPaths` и до пяти необязательных путей в `referencePaths`. Каталог возвращает режим `edit` и ограничения исходников.
- Проверка видео использует `ffprobe` внутри Docker-контейнера. FFmpeg на Mac устанавливать не нужно.

## Проверки выпуска

- Приложение: 64 теста прошли, включая выбор смешанных исходников, MCP и защиту от повторной отправки задачи.
- Backend: 219 тестов и 177 подслучаев прошли; один тест пропущен.
- Проверена загрузка синтетического MP4 через текущий транспорт Google Flow без запуска генерации.
- Собраны DMG и ZIP для Apple Silicon и Intel; проверены состав, архитектура, локальная подпись и контрольные суммы архивов.
- Платная генерация для проверки этого выпуска не запускалась.

## Доступность и ограничения

Каталог и локальные проверки не подтверждают доступ конкретного аккаунта к модели или успешную платную генерацию Veo. Доступ, кредиты и результат запроса определяет Google. Успешная платная проверка всех вариантов Veo для этого выпуска не заявлена.

Если Veo возвращает технический `code=5`, сохраните точное сообщение и проверьте выбранную длительность и тариф в Flow. Сам по себе этот код не доказывает отказ модерации. Приложение не меняет модель и не повторяет платный запрос автоматически.

Сборки для Apple Silicon и Intel остаются Alpha: без подписи Apple Developer ID и нотарификации. Для запуска нужны Google Chrome и Docker Desktop либо Colima с Docker CLI и Docker Compose.
