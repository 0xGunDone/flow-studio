# Обычный Chrome: проверка нативного движка

Новый движок использует macOS Accessibility для штатных элементов Google Chrome. Существующая серверная генерация остаётся отдельным путём; диагностическая подготовка не переключает её автоматически.

## Что можно проверить

В «Настройки» доступны проверка доступа macOS, запрос разрешения, проверка аккаунта в окне Flow и подготовка текстового запроса без генерации. На первом этапе проверяется Omni 1.2 Flash: длительность3–15секунд,16:9/9:16,720p(standard)/360p,count1. Исходные изображения, кадры, Edit и Extend в этом пути пока не проверены и возвращают явную ошибку.

Кнопка подготовки использует текст и модель из редактора, но не нажимает «Начать генерацию». Непустой существующий текст или вложения в веб-редакторе останавливают подготовку, чтобы не перезаписать чужой черновик и не отправить лишние исходники. Название модели, которое Flow не отдаёт через Accessibility, распознаётся локально только в области её кнопки. Для этого macOS может потребовать отдельное разрешение на запись экрана. Для распознавания создаётся временный снимок только области кнопки в закрытой локальной папке; снимок удаляется сразу после чтения и не отправляется внешнему сервису.

## Профили и права

Приложение предпочитает собственный ранее подключённый профиль Chrome. Если аккаунт был добавлен расширением, приложение может найти ровно один соответствующий обычный профиль по метаданным Chrome Local State. Это не чтение cookies или менеджера паролей. Адрес дополнительно проверяется в панели аккаунта самого Flow. Найденное обычное окно остаётся пользовательским: Flow Studio не закрывает пользовательский Chrome.

Аккаунт в списке Flow Studio и профиль браузера — разные записи. Отсутствие app-managed профиля не означает, что аккаунт отсутствует: он может использовать обычный Default/ProfileN. При неоднозначности ничего не выбирается автоматически.

Пока окно проверяется, фоновые синхронизации входа и изменения аккаунтов блокируются. macOS должна быть разблокирована. Не переключайте окно и вкладку во время подготовки: изменившийся фокус останавливает действие.

## Ограничения проверки

Подготовленная форма не доказывает, что Google примет генерацию. Код PUBLIC_ERROR_UNUSUAL_ACTIVITY может остаться и при автоматизации обычного интерфейса. Только отдельно разрешённая одна генерация, сопоставленная с готовым файлом, подтверждает возможность запуска для конкретного аккаунта/профиля. После возможной отправки новая генерация не должна запускаться при неизвестном результате.

## Сборка

```bash
node scripts/build-native.cjs arm64 x64
node app/native/bin/flow-browser-arm64 --self-test
node --test app/browser-native.test.cjs app/accounts.test.cjs
```

Swift helper компилируется дляmacOS14+; чтение видимой подписи модели использует штатный снимок экрана и Vision. Бинарники находятся в игнорируемой папке app/native/bin и включаются в app resources при сборке. Публичный репозиторий хранит исходники helper, не локальные разрешения/профили/снимки.
